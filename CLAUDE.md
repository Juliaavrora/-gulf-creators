# Правила проекта

Источник требований — [SPEC.md](SPEC.md). Как устроен репозиторий — [README.md](README.md).

## Жёсткие правила

1. **Все суммы — `Int` в минорных единицах** (центы, филсы, халалы). Поля называются `*_minor` / `*Minor`.
   Никаких `Float`, `Decimal`, `number` с дробной частью и строк с деньгами. Рядом с суммой всегда хранится валюта (`Currency`).
   Комиссию считаем целочисленно, с явным правилом округления.
2. **Права доступа — только через `access_grants`.** Вопрос «может ли пользователь видеть пост или уровень» решается только по этой таблице
   (и её кэшу в Redis), а не по статусу подписки, `purchases` или данным Stripe.
   Grant появляется только после подписанного webhook платёжного провайдера.
3. **Платежи — только через интерфейс `PaymentProvider`.** Код продукта не импортирует SDK Stripe напрямую: это разрешено только внутри
   реализации провайдера. Клиент никогда не сообщает серверу «оплачено». Webhook-и проверяются по подписи и обрабатываются
   идемпотентно по `provider_event_id`.
4. **Никаких секретов в коде.** Ключи, токены и строки подключения берутся только из переменных окружения.
   Каждую новую переменную добавляем в `.env.example` с пустым значением. `.env.local` не коммитим.

## Прочие соглашения

- Удаления только мягкие: `deleted_at`, `DELETE` по строкам не выполняем. Запросы по умолчанию фильтруют `deleted_at IS NULL`.
- На каждый внешний ключ в Prisma-схеме — `@@index`. Таблицы и колонки в БД в `snake_case` (`@@map` / `@map`).
- Схема БД меняется только через Prisma Migrate (`pnpm db:migrate`).
- Весь текст интерфейса — через next-intl (`apps/web/messages/{ar,en}.json`), без строк в JSX.
  Вёрстка на логических свойствах (`ms-`, `ps-`, `start`, `end`), без `left`/`right`, иначе ломается RTL.
- Дизайн Dibs: макеты — https://claude.ai/artifact/BRxENNjxc8Bf6ty3TCajcq. Цвета только через токены из
  `apps/web/src/app/globals.css` (`bg-bg`, `text-fg`, `bg-surface`, `bg-brand`, `text-accent-fg` …): никаких hex в разметке
  и никаких `dark:`-вариантов — токены сами переключаются между светлой и тёмной темой. Лайм (`brand`) — фон кнопок
  с чёрным текстом; как цвет текста/линий — только `accent-fg`. Шрифт — Rubik (арабский и латиница), логотип — Bricolage Grotesque.
- Клиенты говорят только с API. Ключи внешних сервисов и приём их webhook-ов — только в `apps/api`.
- Не добавлять функции сверх задачи спринта.
